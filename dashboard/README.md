# Dashboard (Web Interface)

Web dashboard (accessible via PC/mobile) reading from the Raspberry Pi database.

- Real-time monitoring
- Historical data & graphs
- Prediction vs actual
- Energy consumption
- Comfort (PMV, Lux, PPD)
- Control status

Includes post-occupancy questionnaire (filled by occupant after room use):
1. Thermal Sensation (-3 to +3)
2. Thermal Satisfaction (1-5)
3. Thermal Preference (Cooler / No change / Warmer)
4. Visual Satisfaction (1-5)
5. Brightness Sensation (1-5)
6. Glare Sensation (1-5)
