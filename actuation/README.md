# Actuation & Environment

ESP node firmware receiving control commands from Raspberry Pi and driving actuators.

- **AC Actuator** — IR AC controller (ON/OFF + T_set)
- **Lighting Actuator** — PWM controllers, Zone 1 (Lamp 1-2), Zone 2 (Lamp 3-4)

**Controlled environment (Living Lab room)**
- Split AC 2 PK
- 4x lamp @ 70W (2 zones)
